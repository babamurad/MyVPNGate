# MyVPNGate

Delphi VCL-приложение для загрузки и проверки списка публичных VPN-серверов [VPN Gate](https://www.vpngate.net/).

## Возможности

- Загрузка актуального списка серверов из API VPN Gate и проверка их доступности (TCP-соединение).
- Таблица показывает **Пинг** (мс) и **Скорость** (Мбит/с), заявленные сервером в VPN Gate, — по ним удобно сразу отсеивать перегруженные/нерабочие узлы, не дожидаясь попытки подключения через OpenVPN-клиент.
- Сохранение списка в `servers.txt` рядом с исполняемым файлом.
- Сортировка таблицы по колонкам **IP**, **Порт**, **Страна**, **Пинг** и **Скорость** — клик по заголовку сортирует список, повторный клик меняет направление; текущая колонка и направление сортировки отмечены стрелкой (▲/▼) прямо в шапке таблицы.
- Контекстное меню по правой кнопке мыши на строке сервера:
  - скопировать IP в буфер обмена;
  - скопировать порт в буфер обмена;
  - заново проверить доступность именно этого сервера;
  - сохранить его конфигурацию в файл `.ovpn`.
- Экспорт `.ovpn`: приложение декодирует встроенный в поток VPN Gate base64-код конфигурации OpenVPN и сохраняет его в готовый файл конфигурации, который можно сразу использовать в клиенте OpenVPN.

> Статус «Работает!» означает только то, что TCP-порт сервера принял подключение (тест на 2 секунды). Это не гарантирует, что через сервер реально пройдёт VPN-туннель — публичные узлы VPN Gate часто перегружены или обрезают долгие сессии. Если конкретный сервер не подключается в OpenVPN/SoftEther, попробуйте другой из списка, желательно с меньшим пингом и большей скоростью.
